# RentMyRide 🚗

A full-stack vehicle rental web application built using Flask (Python) with user, admin, and provider modules.

---

## 🚀 Features
- User Registration & Login  
- Vehicle Booking System  
- Admin Dashboard  
- Provider Vehicle Management  
- AI-based Vehicle Recommendation System  

---

## 🛠️ Tech Stack
- Python (Flask)  
- HTML, CSS, JavaScript  
- SQLite / MySQL
